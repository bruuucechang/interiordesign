使用說明
鍵盤快捷鍵
V/H 平移（拖曳物件移動 / 拖曳空白處移動視角）　N 窗　M 尺寸
WASD 2D 平移視角 / 3D 往視線方向飛（轉了視角就跟著轉）
Shift/Space 3D 升降　Q/E 旋轉選取物件 90°
按住 Alt（Option）暫時關掉吸附（格線、牆端點、家具靠牆）
⌘/Ctrl+C / X / V / D 複製 / 剪下 / 貼上 / 直接複製
⌘/Ctrl+A 全選（略過鎖定與隱藏的圖層）
⌘/Ctrl+S 儲存　+O 開啟　+N 新建　+P 施工圖 PDF
⌘/Ctrl+＋ / − / 0 放大 / 縮小 / 回到 100%
⌘/Ctrl+G 組成群組　+Shift 解散群組
⌘/Ctrl+Z 復原　+Shift 重做
方向鍵 2D 微移物件（+Shift 一格）/ 3D 沿畫面平移，上永遠是畫面的上
Delete 刪除　Esc 取消 / 回到選取
畫牆自動貼合牆端點；近水平/垂直/45° 對齊格線（Shift 強制）
