# 遊戲化：靈敏度、距離衰減、行走模式、介面整理：規格

> 2026-10-28 跟使用者問定。使用者原話：「我要有距離衰減模型 另外要新增一個『可以在裡面行走』的功能
> 不能穿牆 只能穿門 最後我要優化整個介面 現在太雜亂了」「目前靈敏度過高 重新調整」
> 「你自己檢查 以遊戲的風格審視……把這個裝修當成設計房屋的遊戲來看」。
> 切塊在根目錄 `blocks.md` 的 B16～B20。

## 使用者的裁示

| 項目 | 裁示 |
|---|---|
| 距離衰減 | **3D 和 2D 都要**：3D 的燈真的會發光、離得越遠越暗；2D 照度熱圖**加上牆的遮擋** |
| 行走 | **新增「行走」模式**，原本的飛行模式保留；眼睛高度 160 cm、WASD 走路、滑鼠轉頭、不能飛 |
| 碰撞 | **只有牆會擋**（窗戶也算牆）；**門可以穿過**；家具不擋 |
| 樓梯 | **可以走上走下**，走進樓梯就沿著斜坡換到另一層 |
| 靈敏度 | 3D 拖曳轉視角、WASD、滾輪縮放、2D 吸附**都太靈敏**；數值交給我自己定，參考遊戲的手感 |
| 介面 | **改成遊戲式的建造介面**（參考模擬市民的建造模式） |

「遊戲聖經」（`~/Projects/animyria-lanes/bible/docs/bible/03-building.md` 與 `docs/build-design.md` 2.18.1）只定了手把游標的手感
（推一下走一格；按住的話先停 0.25 秒，再以每秒 12 格重複），**滑鼠轉視角、滾輪、吸附都沒有數字**。下面的數字是我參考一般遊戲的慣例定的，都標了「待實測」。

## 一、靈敏度（B16）

量到的現況與新的值：

| 項目 | 現在 | 為什麼太靈敏 | 改成 |
|---|---|---|---|
| 3D 拖曳轉視角 | OrbitControls 預設 `rotateSpeed` 1、`dampingFactor` 0.05 | 放開滑鼠後慣性還會滑很久，看起來像轉過頭 | `rotateSpeed` 0.5、`dampingFactor` 0.15 |
| 3D WASD | `max(300, 場景寬 × 0.7)` cm/s，A1 單元約 10 m/s | 速度跟著場景大小放大，在室內一下就衝出房間 | 固定 250 cm/s，每幀最多算 0.1 秒（卡頓不再一口氣飛出去）。飛行模式的 Shift 已經是「下降」，不另設加速；跑步在行走模式（第三節） |
| 3D 滾輪 | `zoomSpeed` 1 | 觸控板一滑就推好幾公尺 | `zoomSpeed` 0.5 |
| 2D 滾輪 | 每收到一次事件就 ×1.1，不管滑了多少 | Mac 觸控板一次滑動會送出幾十個事件，等於一下就 ×10 | 照 `deltaY` 的量縮放：`exp(−deltaY × 0.0008)`，每次事件最多 ×1.1（滑鼠滾一格 100～120 px 是 ×1.08～1.1，觸控板變成連續縮放） |
| 2D 吸附到牆端點 | 螢幕上 14 px | 畫短牆時會被旁邊的端點吸過去 | 10 px |
| 家具靠牆自動貼齊 | 游標離牆 60 cm 內 | 想讓沙發離牆 40 cm 也辦不到 | 25 cm；**按住 Alt 暫時關掉所有吸附**（模擬市民放家具的慣例） |

另外加一個「操作設定」小面板，放轉視角、移動速度、滾輪、滑鼠轉頭（行走）四條滑桿，存在瀏覽器裡、每台電腦各自記。遊戲一定有這一頁，因為每個人的滑鼠 DPI 不一樣。

## 二、距離衰減

### 2D 熱圖加上牆的遮擋（B17）

- 現在每個房間只算**房間裡面的燈**，所以光不會跑進隔壁房間，但也**不會從門口透過去**；
  L 形房間轉角後面、柱子後面也照樣算得到光。
- 改成：每一盞燈都算，**從燈到量測點的連線碰到牆就擋掉**；連線經過**門**或**窗**的開口就算透過去（門當成開著、窗是玻璃）。
  隔間線（partition）在 3D 本來就沒有實體，所以不擋光。
- 反射光那一項照舊用每個房間自己的燈來算（不跨房間），跟原型一樣。
- **會讓數字跟原型 artifact 對不上**：靠門的區域會多一點從隔壁透過來的光、房間轉角後面會變暗。
  驗收時改成這樣比：**關起來的房間**（門口外沒有燈）數字跟原型一樣（±1%）；另外補「隔壁的燈從門口透過來」和「L 形轉角後面變暗」兩條測試。

### 3D 燈真的發光（B18）

- 每一盞燈變成 three.js 的光源，用物理的平方反比衰減（`decay = 2`）。
  強度用燈的流明換算：崁燈、投射燈是聚光燈，`坎德拉 = 流明 ÷ (2π(1 − cos(光束角/2)))`；吸頂燈、吊燈是往下的半球；T5 和壁燈拆成幾段點光源；色溫換成顏色。
- **光不能穿牆**：要開陰影才擋得住。整間每盞燈都開陰影的話，畫面會卡，所以只處理**你所在的房間以及經過門口連到的房間**裡的燈，
  其中最近的 4 盞投影子，其他的不投影子但照樣只亮自己的房間。這部分屬於「怎麼做」，我會自己決定，回報時再寫明。
- 燈什麼時候亮：時段選黃昏或夜晚時自動打開；白天可以用一個「開燈」開關手動打開。開關群組（迴路）跟 2D 照度面板的勾選連動。
- 驗收：夜晚截一張 A1 單元的圖，要看得到崁燈正下方亮、往外漸暗、隔壁房間沒被照亮（除了從門口透過去的那一片）；切 3D 的時間不能退步超過 B15 的門檻（再切一次 ≤ 200 ms）。

## 三、行走模式（B19）

- 3D 的工具列多一個「行走」按鈕，按 V 也可以切換。進去時角色落在**目前視角正前方最近的地板**上（落點在牆裡的話推到最近的空地）。
- 操作：鎖定滑鼠（點一下畫面開始、Esc 放開）、滑鼠轉頭、WASD 走路、Shift 跑步；**不能飛、不能跳**。
- 數字（待實測）：眼睛高度 160 cm、走路 140 cm/s、跑步 350 cm/s、角色半徑 25 cm、滑鼠轉頭每像素 0.12°（可以在操作設定調整）、上下看最多 ±85°。
- 碰撞：角色是半徑 25 cm 的圓，碰到牆（含窗戶下面的矮牆和窗戶本身）就沿著牆面滑過去，不會卡住；
  **牆上門的開口可以通過**（開口寬度至少要比角色直徑寬；寬度小於 50 cm 的門走不過去）。家具、隔間線不擋。
- 樓梯：家具裡的「樓梯」（`stairs`）是一段斜坡，沿著它的長邊走，高度就從這一層地板線性升到上一層；
  走到頂端時，「目前樓層」切換成上一層。往下走反過來。走到沒有樓梯的樓層邊緣不會掉下去（因為只會被牆擋，所以最外圈一定是牆；沒有牆的地方就是空地，照樣站在這一層的地板高度）。
- 行走時 2D 平面圖的角落（或分割畫面的 2D 那一半）顯示你的位置與面向。
- 在行走模式裡 3D 的娃娃屋剖切關掉，天花板要畫出來（在室內看才像房子）。

## 四、遊戲式建造介面（B20）

參考模擬市民 4 的建造模式：畫面盡量留給房子，工具按分類收起來，選到東西才出現屬性。

- **頂列**只留三樣：左邊放方案名稱與「檔案」選單（新增、開啟、儲存、匯出、底圖），中間是 2D／分割／3D 的切換，右邊放「行走」、時段、復原與重做、說明。
  其餘的小圖示（語言、照度、對齊、縮放比例、全螢幕……）收進「檢視」與「設定」兩個選單。**每個留在頂列的按鈕都要有文字或滑過去的提示**。
- **底部型錄列**：取代現在的左欄。第一排是大分類（結構：牆、曲牆、樑、隔間、門、窗；家具，依房間分成客廳、餐廳、臥室、廚房、浴室、書房；燈與電；樓梯）；
  選了分類才展開第二排的小分類與縮圖，風格篩選與搜尋放在型錄列右上角。一次只看一個分類，不再把三百多件東西攤成一長串。
- **右側屬性**：沒選東西的時候收起來；選了才滑出來。樓層切換改成畫面右下角的小樓層鈕（1F／2F／＋）。
- **語言統一**：介面文字照設定的語言顯示，不再中英混雜（家具名稱目前只有中文，英文介面下顯示中文名稱，這部分照舊）。
- **導覽**：不再一打開就跳出來，改成第一次開空白方案時右下角出現一個小提示「要不要看導覽」，按「說明」選單也可以叫出來。
- 底下的提示列只在有工具作用時才出現。
- 驗收：1440×900 和 1280×800 兩種寬度下都截圖給使用者看；`bench/verify-*.mjs` 裡會點到舊按鈕的腳本跟著改，全部重跑都要通過；
  畫面不重疊（用 inspect-ui 掃）。

## 明確不做

- 家具碰撞（使用者選了家具不擋）、開門關門的動畫、跳躍與蹲下
- 3D 的全域光照與烘焙光照貼圖；日光從窗戶照進來的光在 2D 熱圖裡照舊不算
- 手把操作（遊戲聖經的 2.18.1 是 animyria 的，這裡只用滑鼠與鍵盤）
- 家具名稱的英文翻譯
- 改動 2D 繪圖工具本身的行為（吸附的範圍會改，畫法不變）
