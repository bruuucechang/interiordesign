# 遊戲眼光的第二輪修整（B21～B24）

2026-10-28，B20 合併之後把它當「蓋房子的遊戲」試玩一輪：草稿房間（畫 4×3 m、放門、放床、進 3D、行走、夜晚）＋ A1 單元。
列出 10 個問題，使用者選了四組（「三個會壞的」「放東西的手感」「房間會自己認得」「開場與圖上的字」），另外兩項這次不做（見最後）。

使用者已裁示：
- 家具放在不合理的位置：**警告但照樣放**（預覽變紅、提示列寫原因；地毯、吊燈這類本來就疊放的不算）。
- 房間認出用途後：**只改預設名「房間」**；使用者取過名字的不動，只在旁邊顯示缺什麼。

其餘細節照遊戲慣例由 agent 決定（理由寫在各節）。

## 一、三個會壞的（B21）

1. **只看 3D 時鍵盤指令沒反應。** 實測：3D 模式下 ⌘Z／Ctrl+Z、Delete 都沒作用（`editor.ts` 的鍵盤處理在 `inputEnabled` 為假時整段跳過，而 3D 有焦點時它就是假）。
   改成：⌘／Ctrl 組合鍵（復原、重做、複製、剪下、貼上、直接複製、全選、群組）與 Delete／Backspace 不管哪一格有焦點都照常；只有會跟 3D 移動搶鍵的（WASD、方向鍵、空白、單鍵工具切換 V／H／N／M）維持只給 2D。
   正在打字的輸入框照舊不攔。
2. **一進行走就臉貼著牆。** 現在出生在軌道相機的中心點、面向相機方向；A1 上那個點常落在牆邊，空房間則是面對牆角。
   改成純函式 `walkSpawn`：先找中心點所在的房間（沒有就找這層最大的房間），在房間裡取**離牆最遠的點**（40 cm 格點），朝**視線能看最遠的方向**（每 22.5° 量一條，取最長）。
   離開行走時相機回到**進入前的俯瞰位置**（模擬市民從第一人稱回到建造視角就是回原位），不再停在原地貼著牆。
3. **行走時牆面像馬賽克。** 乳膠漆的貼圖 512 px 鋪 400 cm（每公分 1.28 px），藝術塗料 300 cm（1.7 px），人站在牆前就看到方塊。
   改成每種牆面材質至少每公分 4 px（乳膠漆、藝術塗料改成 120 cm 一張）；加單元測試掃全部牆面材質的密度。

## 二、放東西的手感（B22）

1. **按住 Shift 連續放。** 家具、水電、門、窗：按住 Shift 點，放完東西還在手上，可以接著放；放開 Shift 後的下一次點擊照舊「放一件就回到選取並選起它」。（模擬市民的慣例，現在按 Shift 沒有作用。）
2. **放之前知道放不放得下。** 純函式 `placementIssues(物件, 位置, 平面圖)` 回傳原因清單：
   - 跟別的家具重疊（俯視外框相交超過 5 cm）；地毯類、吸頂／吊掛類、壁掛水電不算，也不擋別人。
   - 不在任何房間裡（中心點不在房間多邊形內，而這層至少有一個房間）。
   - 卡進牆裡（外框跟牆身相交超過 3 cm；靠牆貼齊不算）。
   有問題時 2D 預覽外框變紅、3D 預覽染紅，提示列寫第一個原因（例如「跟雙人床重疊」）；**照樣放得下去**（使用者裁示）。
3. **門窗點在沒有牆的地方要說。** 現在什麼都不發生。改成提示列講「門窗要點在牆上——最近的牆在 N 公分外」。

## 三、房間會自己認得（B23）

純函式 `roomUse(房間, 房間裡的東西)`，照「房間配方」認用途（遊戲聖經 03 章 3.2：DQB2 的房間配方——完成一個明確組合、說得出缺什麼）：

| 用途 | 認得的條件（家具名稱，依序判斷，先符合先用） | 缺什麼（有就不顯示） |
|---|---|---|
| 浴室 | 馬桶、淋浴間、浴缸、坐浴盆 任一 | 燈、排風扇 |
| 廚房 | 爐具／雙口爐／爐台、水槽、抽油煙機 任一 | 燈、抽油煙機（有爐具時） |
| 臥室 | 名稱是「床」結尾或含「床（」的床（**床頭櫃不算**）、上下舖、嬰兒床、榻榻米地台、布團台 | 燈、衣櫃類 |
| 書房 | 書桌類（書桌、L型書桌、木書桌） | 燈、椅子 |
| 餐廳 | 餐桌類（餐桌、圓餐桌、大圓桌、實木長桌、木餐桌、橡木桌） | 燈、餐椅類 |
| 客廳 | 沙發類（名稱含「沙發」） | 燈 |

「燈」＝燈具分類的家具或水電的燈位（吸頂燈、崁燈、投射燈、吊燈、壁燈、T5）。
- 名字還是預設「房間」的，平面圖與 3D 標籤、屬性面板都顯示認出來的用途（「臥室」），**存檔的名字不改**（不產生復原紀錄；使用者一改名就以他的為準）。
- 認出用途而且缺東西時，房名下面多一行小字「缺：燈、衣櫃」（琥珀色）；什麼都不缺不顯示。認不出用途照舊。
- 面積報表（server 產生）照舊用存檔的名字——這塊只動畫面。

## 四、開場與圖上的字（B24）

1. **空白方案的開場。** 這層沒有任何東西時，畫面正中間一張小卡：「從這裡開始」＋兩顆按鈕「畫牆」（打開結構、拿起直線牆）、「匯入平面圖照片」（檔案 → 底圖）。畫下第一樣東西就消失。
2. **導覽提示** 在方案出現第一樣東西時自己收起來（記成看過，不再出現）。
3. **圖上的字不疊在一起。** 平面圖的標籤（房名、面積、缺什麼、家具名、牆長、門窗兩側距離）先排優先順序（選取中＞房名＞缺什麼＞面積＞門窗距離＞家具名＞牆長），在螢幕座標上擺不下的低優先標籤就不畫；放大後有空間再出現。
4. **畫完第一間房鏡頭拉近。** 這層原本沒有房間、畫完牆圍出第一間時，若它在畫面上小於 30%，平滑縮放到它佔畫面約一半（只做這一次，之後不自動動鏡頭）。

## 驗收

- `npm test` 綠；每個純函式（walkSpawn、placementIssues、roomUse、標籤避讓）有單元測試，各自做一次 mutant 看它紅。
- 新 `bench/verify-polish.mjs`（headless、metal）：3D 模式 ⌘Z／Delete 有效；A1 進行走時正前方 2 m 內沒有牆；離開行走相機回原位；
  Shift 連放三件；床疊在床上預覽變紅、提示列有原因、照樣放下；門點空地有提示；放床後「房間」顯示「臥室」與「缺：燈」；空白方案有開場卡、畫第一道牆後消失；小房間標籤不重疊。
- 既有 `bench/verify-*.mjs`、`shot-b20.mjs` 照跑通過；1440／1280 截圖給使用者看。

## 這次不做

- 夜晚俯瞰時只有中間幾間亮（同時只亮 12 盞的限制）——試玩列出、使用者這次沒選。
- 空間健檢的紅色數字分級——同上。
- 家具碰撞（行走時）、開門動畫、家具名英文：沿用 B16～B20 的「明確不做」。
