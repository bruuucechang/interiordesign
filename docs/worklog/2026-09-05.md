# 2026-09-05 工作日誌

## 做了什麼

- 改善相容性，讓不支援 3D 顯示的電腦仍能使用 2D 平面圖編輯器。
- 讓同步失敗與離線狀態清楚顯示，提供重試，並修正部分方案無法同步的問題。
- 新增回收桶，刪除的方案可在 30 天內還原；也避免空白的新方案自動佔滿清單。
- 增加方案擁有者區隔與多人修改衝突提醒，讓使用者能另存版本，保住各自的修改。
- 改善牆面對齊提示與鍵盤操作，支援記住略過的項目、常用快捷鍵和精確輸入牆長與角度。
- 加快大型方案的編輯反應，並改善畫面提示與無障礙操作。
- 新增可隨時跳過或重新開啟的新手教學，支援繁體中文、英文及英制單位。
- 完善 Windows 桌面版安裝與使用說明，補齊家具素材，並修正程式無法啟動的問題。

## 決定與理由

- 牆面落差全部略過後不再常駐提醒；需要時選取多道牆，仍可重新顯示，兼顧畫面簡潔與可還原。
- Windows 版採用安裝精靈，讓不熟悉電腦的使用者不必自行解壓縮即可安裝使用。
