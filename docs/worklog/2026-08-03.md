# 2026-08-03 工作日誌

## 做了什麼
- 更新系統架構，讓空間計算交由後端處理，同時保留操作時需要即時反應的功能。
- 改善底圖牆線辨識，讓不同角度的牆都能被偵測，並新增 DXF 圖面牆線匯入。
- 新增樓層與房間面積統計、家具及物件數量彙整，並可匯出 Excel。
- 新增家具顏色選擇、物件群組，以及依門窗和牆面交會處自動產生連續尺寸標註。
- 為 3D 空間加入天花板，並新增插座、開關與燈具的水電配置圖層。
- 完成可下載的獨立應用程式與 Docker 部署方式，並驗證 Docker 可正常啟動。
- 改善 3D 畫面的渲染效能，讓不同效能的電腦能更順暢地操作。

## 決定與理由
- 暫不提供直接匯入 DWG：測試過的開放工具無法可靠讀取或轉換圖面，因此改為說明先轉成 DXF 的方式。
- 天花板會配合觀看方式顯示，避免從上方檢視時遮住整個平面配置。
