# 全屋燈光配置（plan1151022，B6）

> 2026-10-22。方案 `plan1151022`（天花板 300）。Bruce 房、老媽房是 B5 照原型擺的，
> 其餘六個空間是 B6 排的。配置在 `scripts/furnish-b5.mjs`、`scripts/furnish-b6.mjs`，
> 數字用下面的指令重跑，不要抄這份表：
>
> ```bash
> npm run dev
> node scripts/furnish-b6.mjs --save               # 只換 b6_* 物件，重跑安全
> cd client && npx tsx ../scripts/report-b6.mts --db  # 每間的整間平均、區域、達標區域、健檢；exit 0＝過
> cd .. && node bench/verify-b6.mjs                # 面板數字＝腳本數字，截圖 bench/results/b6-*.png
> ```
>
> 看法一律是：桌面 75 cm、全部迴路開著、中間色牆面（ρ 0.45）、維護係數 0.8。
> 不算日光、調光、家具擋光（規格「明確不做」）。不含購買清單與估價。

## 達標標準（假設，請確認）

規格只定了臥室的區域（床面 ≥100、書桌 ≥300、做到頂的櫃子前 ≥100、門口 ≥100）。
客廳、廚房、衛浴、陽台沒有床或書桌，App 自動生出的只有門口與櫃子前，所以 B6
**另外定了下面這些目標**——數字取 CNS 12112 住宅照度一般值的**下限**，是假設：

| 空間 | 目標 | 依據 |
|---|---|---|
| 臥室整間平均 | ≥ 150 | B5 兩間 230～280；一般照明夠，床頭閱讀另開床頭燈 |
| 客廳＋廚房整間、客廳那一塊 | ≥ 150 | CNS 客廳 150～300 |
| 玄關、走道 | ≥ 100 | 跟門口區域同一個標準 |
| 流理台面（量測高度 85） | ≥ 300 | CNS 廚房工作面 300～500 |
| 衛浴整間 | ≥ 100 | CNS 浴室 100～200 |
| 洗手台前 60 cm | ≥ 200 | 洗臉、刮鬍子要看清楚臉，比整間高一級 |
| 陽台整間 | ≥ 50 | 晾衣、通行用 |

另外每間都要：均勻度（最暗 ÷ 平均）≥ 0.4、健檢沒有任何提醒。

### Peter 房

床頭靠西牆。崁燈全部放在離枕頭水平 200 cm 以外（天花板 300、枕頭高 60，40° 以內
躺著會看到），所以床那一側只靠 T5 與反射光，床面 191 仍有餘。

- 迴路 1：東牆兩支 T5 4 尺，朝西（洗牆，間接光）
- 迴路 2：衣櫃頂面兩支 T5 4 尺，朝北（衣櫃前與房間中段）
- 迴路 3：崁燈 7 盞——中段到東側 2 × 3、北側凸窗一盞

均勻度 0.42 是八間裡最低的：西北角弧形窗那一帶離每一盞燈都遠。

### 老爸房

PDF 沒畫家具，排成「床放哪都夠」的一般照明：東西兩面牆各一支 T5 4 尺（迴路 1）、
崁燈 2 × 3（迴路 2）。之後放了床，崁燈要照 Peter 房的做法避開枕頭上方。

### 客廳＋廚房

同一個房間物件，含玄關、臥室門前的走道、東側三扇門前的小廳、客廳、廚房。

- 迴路 1：玄關 2、走道 4、東側小廳 2 盞崁燈（進門、走動）
- 迴路 2：客廳 2 × 3 崁燈
- 迴路 3：廚房崁燈 5 盞（流理台上方 3、西段 1、冰箱前 1）
- 迴路 4：檯面燈——流理台上方的牆面、離地 150 的 T5 3 尺 ×3（南牆窗的兩側、西段）。
  PDF 沒有吊櫃，光靠天花板崁燈台面只到 270 上下（再加崁燈也只會更擠），所以用貼牆的
  檯面燈；要是之後做吊櫃，換成吊櫃下的層板燈就好。

### 衛浴 A、衛浴 B

崁燈當一般照明（迴路 1），洗手台上方的牆、離地 200 加一支 T5 當鏡前燈（迴路 2）。
淋浴間的燈要選防水型——這裡只排位置，不綁型號。

### 陽台

三盞崁燈，一盞在陽台門內側（門口區域原本只有 70）。戶外用要選防潮型。
