# 分層顯示、燈具種類、溫潤木質傢俱、A1 豪宅版（B28～B31）

2026-10-29，B27 合併之後使用者說：「我想要分層，燈可以勾選隱藏只看到實際房間；另外燈要有很多種，幫我把現在的燈換掉，
做成 LED 鋁燈＋崁燈的全屋設計，高級豪宅風；現在的傢俱也是醜的沒邊，換成合適的。」

使用者已裁示：
- 改哪份：**另存一份「A1 豪宅版」來改**，A1（plan1151022）原樣不動。
- 分層：**2D 跟 3D 都能藏，頂列一組勾選**。
- 傢俱醜的是：**3D 裡的模型**（例如 A1 的衣櫃在 3D 是深褐色雕花古董櫃）。
- 換法：**重做一套豪宅風 3D 傢俱再替換**。
- 豪宅的定義：**溫潤木質低調奢華**——淡橡木、米白、亮面石材、布紗質感（日式豪宅、北歐低調奢華），**不是**深色古董、不是金色輕奢。
- 客餐廳：**補上基本配置**（沙發、茶几、電視櫃、地毯、餐桌椅），位置照動線擺，使用者不喜歡再拿掉。

其餘細節（燈的型號與數量、材質色號、擺位）由 agent 參考實際案例決定，回報時列出。

## 一、分層顯示（B28）

1. 頂列一個「顯示」下拉，四個勾選：**燈具**（水電的燈位＋家具目錄的燈具）、**插座開關**、**家具**、**尺寸與標註**（尺寸線、子區域）。
   全部取消＝只剩牆、門窗、房間（使用者說的「只看實際房間」）。
2. 取消勾選的東西 **2D 與 3D 都不畫**、也點不到（不能選、不能拖）；照度計算照舊算（燈藏起來房間照樣亮），照度熱圖照舊。
3. 勾選狀態是**看圖的人自己的設定**（存瀏覽器），不寫進方案、不產生復原紀錄、不影響匯出（PNG／施工圖照舊全畫）。
4. 跟「檢視 → 圖層」的關係：圖層是方案的一部分（鎖定、顏色），照舊；「顯示」是看的時候的濾鏡，兩者都要開著才畫。

## 二、燈具種類（B29）

現在水電燈位只有吸頂燈、嵌燈、投射燈、吊燈、壁燈、T5 燈管、排風扇幾種，家具目錄另有吸頂燈、吊燈、立燈等。
加一組豪宅常用的、台灣燈具行買得到的規格（色溫一律 3000K，流明照常見產品）：

| 類 | 新增 | 用途 |
|---|---|---|
| LED 鋁擠燈（線燈） | 嵌入式鋁擠線燈（天花溝槽，長度可調）、明裝鋁擠線燈、間接燈槽（往上打天花）、洗牆鋁擠燈（往下洗牆／衣櫃面）、櫃內層板燈 | 全室基礎照明與氛圍 |
| 崁燈 | 無邊框崁燈（7.5 cm 開孔）、深藏防眩崁燈、可調角度投射崁燈、洗牆崁燈、雙頭格柵崁燈 | 重點與作業照明 |

1. 每一種都有：2D 平面符號（B25 的安靜畫法）、3D 外觀（崁燈是天花上的圓孔、鋁擠燈是天花或牆上的發光細條）、照度計算用的光通量與配光（線燈依長度算流明）。
2. 線燈跟 T5 一樣可以調長度（拖端點或在屬性面板打數字）。
3. 照度計算的公式不動（`lighting.ts`），只新增燈的資料。

## 三、溫潤木質低調奢華傢俱（B30）

用程式產生（跟目錄裡現有的「現代」款同一套做法），一套風格一致的新款，加進家具目錄、風格篩選多一個「溫潤奢華」：
- 材質：淡橡木、米白布紗、亮面米色石材（檯面）、霧面香檳金屬細節（很少量）、淺灰石紋。
- 款式（A1 用到的＋客餐廳要補的）：雙人床、床頭櫃、衣櫃（無把手、木紋門片、可對開／推拉）、書桌、高櫃、鞋櫃、廚房上下櫃、中島或流理台、冰箱（嵌入）、
  馬桶（壁掛）、浴櫃洗手台（石材檯面）、淋浴間（玻璃）、沙發（L 型布沙發）、茶几、電視櫃、地毯、餐桌、餐椅。
- 2D 平面符號沿用 B25 的灰色畫法；3D 才是這次的重點。

## 四、A1 豪宅版（B31）

1. 另存 A1 成新方案「A1 豪宅版」（同一個 owner），之後只改這份。
2. **燈**：拿掉全部 57 盞嵌燈與 21 支 T5，照房間重新配：天花溝槽鋁擠線燈＋間接燈槽當基礎照明，崁燈打重點（床頭、書桌、廚房檯面、鏡櫃、走道），
   衣櫃前用洗牆燈；**每間房的照度要過空間健檢的照明標準**（床面、書桌、櫃前與門口那幾條），過不了就調到過。
3. **傢俱**：29 件換成 B30 的對應新款（尺寸照原位，不夠放就微調）；客廳補 L 型沙發、茶几、電視櫃、地毯，餐廳補餐桌＋4 椅。
4. 地板與牆面材質順便換成溫潤木質（淡橡木地板、米白牆），衛浴照舊用石材磚。
