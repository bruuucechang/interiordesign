# 畫面減量（B25～B27）

2026-10-29，B24 合併之後使用者說「繼續優化 畫面太亂」，選了「全部都是，從頭審一遍」。
截了 10 種畫面（並排、選取家具、打開家具列、純 2D 全圖與放大、檢視選單、側欄、3D、行走、1280 寬），整理成四組，使用者四組都要做。

使用者已裁示：
- 家具名字：**放大到看得清時＋選取時**才出現。
- 牆長：**縮小只標長牆，放大標全部**（選取中的牆永遠標）。
- 「檢視」上的紅色 22 與右上的「牆面對齊 (2)」：**數字拿掉、對齊收進空間健檢**。

其餘細節照慣例由 agent 決定（理由寫在各節），回報時列出假設。

## 一、平面圖的黃色（B25）

實測 A1：57 顆嵌燈（`downlight`，實心黃點）、21 條燈條（`batten`，貼牆的黃條）、家具外框（`#e0b45a`）、5 塊子區域（黃色虛線）、琥珀色「缺：…」——五種東西同一個顏色，燈點還蓋在房名上（「老媽房間」「衛浴 B」被壓到）。

1. **只有燈是黃的。** 家具外框與家具名改成不搶眼的暖灰；子區域虛線改成淡灰；「缺：…」維持琥珀色（它是唯一要人注意的字）。
2. **嵌燈變小變淡。** 實心大黃點改成小的空心圈（細線、半透明），蓋在房名上也看得到底下的字。圖層順序不動（燈仍在房名之上——U6 的理由：燈放在房名上要看得出放了）。燈條變細、半透明。
3. **照度熱圖開著時照舊**：燈要用迴路顏色、看得清楚，那時不減。
4. **不改方案資料。** 實作時查到：家具的琥珀色寫死在 29+ 個家具圖形裡、子區域的黃色寫死在 renderer，都不是圖層顏色——所以在畫平面圖時換色（`core/planInk.ts::quietInk`），圖層顏色與方案資料都不動。家具目錄的小圖與 3D 照舊。
5. 匯出 PNG／施工圖 PDF 照舊（施工圖本來就是黑白）。

## 二、地板條紋（B25）

木地板等材質的平面圖紋路（`materials.ts` 的 hatch）對比太強，整張圖像斑馬紋。

1. 紋路明顯變淡（降到牆線、家具線之下一級）。
2. **紋路間距在螢幕上小於約 20 px 時不畫**，只留底色——看全圖時沒有條紋，放大到看得出木紋時才出現。
   間距從每種材質的紋路小圖量出來（A1：木地板 30 cm、磨石子約 37 cm、60 cm 磁磚 64 cm）；A1 全圖（2D 約 0.5 px/cm）木紋 15 px 不畫，磁磚格 32 px 照畫。
3. 施工圖 PDF 照舊。

## 三、圖上的字（B26）

1. **家具名**：家具在螢幕上的大小放得下它的名字（字的底框塞得進家具外框）時才畫；選取中的家具永遠畫。描圖帶進來的自訂名一樣處理。
2. **牆長**：牆在螢幕上的長度比它的數字底框長（留邊）才畫；選取中的牆永遠畫。看全圖時短牆段（65 cm、93 cm 這類）不標，放大到放得下就出現。樑的淨高（「↥2.40 m」）沿樑標，同一條規則。尺寸線（使用者自己畫的標註）照舊。
3. 跟 B24 的避讓疊加：先依上面兩條決定「有沒有資格畫」，再依優先順序避讓。
4. 匯出照舊全部畫（紙本不能放大，同 B24）。

## 四、介面角落（B27）

1. **「檢視」上的數字拿掉。** 空間健檢有幾項提醒，只在打開「檢視」選單後那一列的數字看得到（那裡本來就有）。
2. **「牆面對齊 (2)」不再常駐右上角。** 變成空間健檢清單裡的一項（點了照舊開側欄的對齊列表、照舊能「全部略過」）。
3. **3D 底下的 WASD 鍵盤圖**：只在滑鼠移到 3D 那一格、或按著移動鍵時出現，平常不顯示。
4. **行走時的兩行操作提示**：進入行走時出現，6 秒後淡出；滑鼠移到畫面下緣附近時再出現。
5. 「2D 平面」「3D」角標維持（並排時分辨兩格要用）。

## 驗收

- `npm test` 綠；「家具名放不放得下」「牆長放不放得下」「琥珀換灰」「紋路畫不畫／紋路間距」寫成純函式，有單元測試，各自做一次 mutant 看它紅。
- 新 `bench/verify-declutter.mjs`（headless、metal、API 只放行 GET、A1 只讀）：A1 全圖時平面圖上沒有實心黃點（量嵌燈畫的方式）、家具框不是黃色、條紋在全圖不畫／放大後畫；
  全圖時 65 cm 這類短牆不標、放大後標；全圖時家具名少於放大後、選取的家具一定有名字；「檢視」上沒有數字；右上沒有「牆面對齊」、空間健檢裡有它；
  3D 平常沒有鍵盤圖、滑鼠移上去才有；行走提示 6 秒後消失。A1 仍 180 件。
- 既有 `verify-polish`、`shot-b20`、`verify-b13` 等照跑通過；1440／1280 前後對照截圖給使用者看。

## 這次不做

- 3D 畫面本身（材質、家具模型、光線）——審查列出的四組都不含它；只動 3D 上面的鍵盤圖與行走提示。
- 改方案資料（圖層顏色、家具名字都不寫回）。
- 匯出（PNG、施工圖 PDF）的樣子。
- 照度、碰撞等計算。
