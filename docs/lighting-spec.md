## 明確不做

- **購買清單、型號綁定、估價**：使用者這次沒選。燈具只有種類與數字，不綁產品型號
- **電氣迴路（配線）**：這裡的「迴路」只是分析用的**開關群組**，不畫線、不算線徑、
  不出配電圖。notebook 記的「暫不做迴路」指的是配線，那一條照舊
- **調光模擬、日光／窗外的光、家具擋光、3D 光照渲染**：跟 artifact 一樣不算，
  面板上要明講
- **不覆寫既有方案**：平面圖修正與排燈都存成**新的一份方案**，原本的
  `img0199-restored` 不動（design-rules 9.3：不可逆的動作要有回頭路）

## 計算方式（跟 artifact 一致，驗收拿它對數字）

- 崁燈、吸頂燈、投射燈：往下的朗伯光源（cosⁿ，n 由光束角換算；120° → n=1）
- T5 層板燈、壁燈：每支切 16 段，當成貼牆的半圓柱燈管，朝房間那一半發光、
  往管子兩端漸暗；強度 I₀ = 2Φ / π² / 段數
- 吊燈：往下的朗伯光源，高度取它自己的 elevation
- 反射光：整間平均，Φ × ρ ÷（室內總表面積 ×（1 − ρ））；ρ 三檔 0.55／0.45／0.3
- 全部乘維護係數 0.8
- 量測高度三檔：桌面 75、床面 55、地面 0
- 每個房間（room 物件）分開算；做到頂的櫃子當成擋住的格子

## 區域與檢查

區域自動從圖上生出來，跟 artifact 相同：床面（55，需 ≥100）、書桌面（75，需 ≥300，
不夠提示加檯燈）、做到頂的櫃子前 50 cm（需 ≥100）、每扇門內側 80 cm（需 ≥100）。

檢查只回報、永不打斷，接進現有的空間健檢（design-rules 第十節的三條界線照守）：

1. 燈在枕頭上方附近：從枕頭往上看偏離正上方 < 30° 報、30～40° 提醒；床頭後方的降為提醒
2. 崁燈離做到頂的櫃子 < 25 cm；崁燈裝在做到頂的櫃子上方
3. T5／壁燈沒貼在牆或櫃子面上；跨在門上方
4. 整間均勻度（最暗 ÷ 平均）< 0.4
5. 各區域未達標
